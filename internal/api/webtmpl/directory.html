Publishing

Anybody can browse this registry. Publishing needs an account, and GitHub is the only way in: artifacts live on GitHub Releases and the ownership records this registry was migrated from are GitHub handles, so a GitHub identity is the one credential that connects a publisher to the code they are publishing.

What that looks like from a plugin repository — the template to start from, the scoped token, the one job you add to your release workflow, and what the first release actually does — is on how to publish a plugin.
