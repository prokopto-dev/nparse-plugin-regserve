The tier belongs to the account, not to this plugin. It applies to every plugin this person holds, now and in future — there is deliberately no per-plugin trust (ADR-0007).

This is a separate decision from approving anything. Trust is never raised as a side effect and never automatically: there are no publish counters and no thresholds, because a counter is something an attacker can run up — publish four harmless releases, earn the tier, publish the fifth.

What trusted changes is narrow. A version bump of an already-approved plugin can publish without a human, and only when this server fetched the artifact and re-hashed it clean and no quarantine rule fired. A new plugin id always gets a human, whatever the tier — that is where impersonation is caught, and nothing here weakens it. It never governs who may review, which comes from REGSERVE_REVIEWERS and nothing else.

A reason is required. The tier itself is an upsert and carries only the current value; the history is in the audit log, which nothing can edit, and this note is the only place the reasoning survives.
