“delisted” means the listing was removed and the claim was kept. A plugin id is permanent, first-come and never recycled — it names the plugin in every installed copy on every user’s machine — so a delisted id is spoken for for ever and by nobody else. Nothing on this surface deletes a plugin, and a database trigger refuses one.

The tier beside an owner is that account’s, not that plugin’s. The same person shows the same tier against every plugin they hold; there is deliberately no per-plugin trust (ADR-0007).
